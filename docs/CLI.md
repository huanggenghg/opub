# opub CLI

本页是面向用户的统一命令行说明。`opub` 通过一个命令完成素材准备、账号检查和多平台发布；每个平台只自动发现一个规范账号文件。

## 安装

```bash
pip install opub
opub --version
```

首次运行会创建 `~/.opub/` 数据目录。浏览器自动化需要 Chromium，图文转视频还需要 ffmpeg；安装失败时按命令行给出的 `ENV-xxx` 建议处理。

## 发布

视频：

```bash
opub --platforms douyin,weibo --video videos/demo.mp4 --title "标题" --tags "标签1,标签2"
```

图文：

```bash
opub --platforms xiaohongshu --note --images img1.jpg,img2.jpg --title "标题"
```

定时、断点续传和强制重新生成：

```bash
opub --platforms weibo --video videos/demo.mp4 --schedule "2026-08-21 12:00" --start-from 2 --force
```

素材路径、标题、描述、标签和目标平台应由用户明确提供；一个规范账号文件对应一个平台账号。发布成功后命令会输出各平台结果及链接。

## 付费许可

一次购买 ¥9.90，许可绑定一个设备。首次激活后永久离线使用，不需账号。许可不迁移、不解绑、不提供换机重置；新电脑重新购买。公开 Python 包是诚实用户门禁，属于非强 DRM，不是强制性防破解方案。

查看许可状态：

```bash
opub --license-status
```

首次激活（选择一种支付方式）：

```bash
opub --activate --pay-with wechat
opub --activate --pay-with alipay
```

首次激活需要网络打开付款窗口；激活成功后发布可永久离线运行。没有账号体系，也没有迁移、解绑或换机重置流程。

### Agent 使用流程

Agent 必须先保留已经确认的发布输入，并在发布前静默运行 `opub --license-status`。退出码为 13 时询问用户使用微信还是支付宝，然后分别执行上面的激活命令。Agent 只告知“付款窗口打开”，不得展示设备 hash、poll token、form 或 internal log。激活成功后自动继续原发布任务，不重复询问参数。

### 许可错误与建议

错误格式为 `[opub] LICxxx: <描述>。建议: <动作>`。

| 错误码 | 含义 | 建议 |
| --- | --- | --- |
| `LIC001` | 未激活 | 选择支付方式并执行激活命令 |
| `LIC002` | 激活失败 | 按付款窗口提示完成支付后重试 |
| `LIC003` | 付款未完成 | 完成付款后重新运行激活命令 |
| `LIC004` | 签名或许可数据无效 | 联系支持并提供错误码 |
| `LIC010` | 设备已绑定其他许可 | 新电脑重新购买 |
| `LIC011` | 不支持迁移、解绑或换机重置 | 使用原设备，或新电脑重新购买 |
| `LIC012` | 许可服务暂时不可用 | 稍后重试；首次激活前恢复网络 |

退出码 `13` 表示需要首次付费激活。发布本身仍使用稳定退出码：`0` 全部成功、`1` 部分成功、`2` 全部失败、`10` 配置错误、`11` 环境错误、`12` 登录未完成。

## 结果与错误

流程错误写入 stderr：

```text
[opub] <错误码>: <描述>。建议: <可执行的动作>
```

发布汇总写入 stdout，并包含平台成功/失败、`PUB-<platform>` 错误码、结果链接和总体计数。配置问题看 `CFG-xxx`，环境问题看 `ENV-xxx`，登录问题看 `AUTH-xxx`；不要把内部调试日志当作用户结果。
