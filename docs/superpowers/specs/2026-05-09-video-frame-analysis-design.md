# 视频帧分析功能重构设计

## 概述

重构 `sau generate` 命令，移除占位符实现，使用 Claude Code 多模态能力直接分析视频帧图像，生成标题和描述。

## 需求

1. **移除占位符** - 删除 `analyze_video_content()` 中的默认实现
2. **两阶段执行** - 帧提取并发执行，内容分析串行执行
3. **独立帧存储** - 每个视频的帧保存在独立文件夹中
4. **通用风格** - 标题简洁概括内容，描述客观描述画面

## 架构设计

### 执行流程

```
sau generate --dir videos/
       │
       ▼
┌─────────────────────────────────────────┐
│ 阶段1: 并发帧提取                        │
│                                         │
│ 视频A ──→ 提取帧 ──→ temp_frames/视频A/  │
│ 视频B ──→ 提取帧 ──→ temp_frames/视频B/  │  (并发)
│ 视频C ──→ 提取帧 ──→ temp_frames/视频C/  │
│                                         │
│ 每个文件夹包含: frame_0.png, frame_1.png, frame_2.png
└─────────────────────────────────────────┘
       │
       ▼ (所有帧提取完成)
┌─────────────────────────────────────────┐
│ 阶段2: 串行内容分析                       │
│                                         │
│ for each 视频文件夹:                     │
│   1. 读取 3 张帧图像                     │
│   2. 调用大模型分析生成标题描述           │
│   3. 保存到同名 .json 配置文件            │
│   4. 清理临时帧文件夹                    │
└─────────────────────────────────────────┘
```

### 文件结构

```
temp_frames/
├── 视频1/
│   ├── frame_0.png  (开头帧)
│   ├── frame_1.png  (中间帧)
│   └── frame_2.png  (结尾帧)
├── 视频2/
│   └── ...
└── ...

videos/
├── 视频1.mp4
├── 视频1.json      # 生成的配置文件
├── 视频2.mp4
├── 视频2.json
└── ...
```

### 配置文件格式

```json
{
  "title": "厨房收纳技巧分享",
  "desc": "展示了厨房整理收纳的实用方法，包括抽屉分隔、调料架摆放等技巧。",
  "generated_at": "2026-05-09T14:30:00",
  "video_file": "视频1.mp4"
}
```

## 修改内容

### 1. 重构 `utils/video_analyzer.py`

**删除：**
- `analyze_video_content()` 函数（占位符实现）

**修改：**
- `extract_frames()` - 返回帧文件夹路径而非帧文件列表
- `generate_video_configs()` - 分离帧提取和分析阶段

**新增：**
- `extract_all_frames_parallel()` - 并发提取所有视频帧
- `analyze_frames_folder()` - 分析单个视频帧文件夹

### 2. 修改 `sau_cli.py`

**修改 `dispatch()` 函数中的 generate 处理逻辑：**
- 阶段1: 调用并发帧提取
- 阶段2: 逐个读取帧文件夹，调用大模型分析
- 阶段3: 保存配置并清理临时文件

### 3. 分析提示词

```
分析这3张视频帧图像，生成标题和描述。

要求：
- 标题：简洁概括视频内容，15-25字
- 描述：客观描述画面内容，50-80字
- 风格：通用风格，适配多平台

请以 JSON 格式返回：
{"title": "...", "desc": "..."}
```

## 错误处理

1. **帧提取失败** - 记录错误，跳过该视频
2. **分析失败** - 记录错误，不生成配置文件
3. **配置文件已存在** - 默认跳过，`--force` 时覆盖
