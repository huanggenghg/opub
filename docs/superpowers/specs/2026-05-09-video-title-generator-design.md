# 视频标题描述自动生成功能设计

## 概述

为 `social-auto-upload` 项目添加视频标题描述自动生成功能，通过分析视频画面内容，自动生成匹配的标题和描述，并存储为独立的配置文件，在发布时自动匹配对应视频。

## 需求

1. **分析方式**：直接分析视频画面内容生成标题和描述
2. **存储方式**：每个视频生成独立的 JSON 配置文件
3. **触发时机**：手动批量生成（提供 CLI 命令）
4. **品牌信息**：根据内容自然生成，不强制加入品牌名
5. **标签生成**：只生成标题和描述，不生成标签

### 配置文件格式

每个视频生成一个 JSON 文件，与视频同名，存放在视频同目录下：

```json
{
  "title": "懒人福音！追觅电视一键投屏太方便了",
  "desc": "不用起身就能投屏追剧，追觅电视让懒人生活更美好。一键操作，简单便捷，宅家必备神器。",
  "generated_at": "2026-05-09T10:30:00",
  "video_file": "懒人福音1.mp4"
}
```

**字段说明**：
- `title`: 视频标题
- `desc`: 视频描述
- `generated_at`: 生成时间（ISO 8601 格式）
- `video_file`: 对应的视频文件名

## CLI 命令设计

### 命令格式

```bash
# 基本用法：生成指定目录下所有视频的标题/描述
sau generate --dir videos/20260509/

# 强制覆盖已存在的配置文件
sau generate --dir videos/20260509/ --force

# 只生成指定视频的配置
sau generate --file videos/20260509/懒人福音1.mp4
```

### 参数说明

| 参数 | 说明 | 必需 |
|------|------|------|
| `--dir` | 视频目录路径 | 与 `--file` 二选一 |
| `--file` | 单个视频文件路径 | 与 `--dir` 二选一 |
| `--force` | 强制覆盖已存在的配置文件（默认跳过） | 否 |

## 发布流程修改

修改 `publish_all.py` 的内容获取逻辑，优先级如下：

1. 视频同名的 JSON 配置文件
2. 默认配置文件中的标题/描述
3. 模板随机填充

## 视频分析实现

### 关键帧提取

使用 OpenCV 或 ffmpeg 提取视频关键帧：
- 提取视频开头、中间、结尾三帧
- 或按固定间隔提取多帧

### 内容分析

将提取的帧图像作为多模态输入，分析：
- 画面主题和场景
- 产品或人物特征
- 文字信息（如有）
- 整体风格和氛围

### 生成规则

1. **标题**：简洁有力，突出核心卖点，控制在 20 字以内
2. **描述**：补充细节，增加吸引力，控制在 100 字以内
3. **风格**：自然、真实，符合短视频平台调性

## 错误处理

1. 视频文件无法读取：跳过并记录错误
2. JSON 文件已存在：默认跳过，`--force` 时覆盖
3. 分析失败：记录错误，不生成配置文件
